### 4. Implemented Token Refresh Logic ✅

**File:** `lib/services/http_client.dart`

**New Features:**
- `_isRefreshing` flag prevents concurrent refresh attempts
- `_pendingRequests` queue handles requests during refresh
- Automatic token refresh on 401 errors
- Request retry with new token after successful refresh
- Auto-logout and token clearing on refresh failure

**Implementation Details:**
```dart
1. Detect 401 error in _onError interceptor
2. Retrieve refresh token from secure storage
3. If refresh already in progress, queue the request
4. Call /auth/refresh endpoint
5. Save new tokens on success
6. Retry original request
7. Process all queued requests
8. On failure, clear tokens (triggers auto-logout)
```
